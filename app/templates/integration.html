问题反馈接入

 
接口：/api/client/feedback，POST multipart/form-data。验证成功的签名响应中包含短期 feedback_token，使用 Authorization: Bearer 发送；该令牌只能提交反馈，不能操作后台。

 
metadata 字段是 JSON，包含 submission_id（UUID）、app_version、description、contact（可选）；logs 是可选 ZIP 文件，最大 15 MB，仅支持日志和 JSON、TXT 文本。版本号支持精确筛选；超时重试应复用提交编号和同一个 ZIP。

 
# client.verify(card) 成功后，由 SDK 自动携带反馈令牌
import uuid
submission_id = str(uuid.uuid4())  # 重试时保留此编号
receipt = client.submit_feedback(
    app_version="0.1.2",
    description="点击导出后程序提示失败，重新打开项目后仍可复现。",
    logs_path="logs.zip",  # 可不传，仅提交文字
    contact="可选联系方式",
    submission_id=submission_id,
)
print("反馈编号：", receipt["id"])
